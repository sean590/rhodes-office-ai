# Dependency audit exceptions

Advisories ignored via `pnpm.auditConfig.ignoreGhsas` in `package.json`.
Each entry needs a rationale and a revisit condition. Remove an entry as soon
as a compatible patched version exists.

Reviewed: 2026-07-27 (post-Next.js 16.2.12 upgrade, security audit P0-1).

## GHSA-mh99-v99m-4gvg — brace-expansion (high)

- **Path:** `exceljs > archiver > (archiver-utils|readdir-glob) > minimatch > brace-expansion@1.x/2.x`
- **Issue:** DoS via unbounded brace expansion of an attacker-controlled pattern.
- **Why not applicable:** the vulnerable code is only reached when minimatch
  globs a pattern; archiver only globs internal file paths generated by exceljs
  when writing xlsx zips. No user-controlled pattern reaches it.
- **Why not patched:** the fix exists only in brace-expansion 5.x; minimatch
  1.x/2.x consumers (glob@7, readdir-glob) cannot use it without breaking.
- **Revisit when:** exceljs or archiver ship a release on modern glob/minimatch,
  or a 1.x/2.x backport is published.

## GHSA-w5hq-g745-h8pq — uuid (moderate)

- **Path:** `exceljs > uuid@8.3.2`
- **Issue:** missing buffer bounds check in v3/v5/v6 when a `buf` argument is
  provided.
- **Why not applicable:** exceljs only calls `uuid.v4()` with no buffer
  argument.
- **Revisit when:** exceljs updates its uuid dependency.

## GHSA-frvp-7c67-39w9 — @hono/node-server (moderate)

- **Path:** `@modelcontextprotocol/sdk > @hono/node-server@1.x`
- **Issue:** path traversal in `serve-static` on Windows via encoded backslash.
- **Why not applicable:** production runs on Vercel Linux, and the MCP SDK does
  not use the `serve-static` middleware.
- **Revisit when:** @modelcontextprotocol/sdk (currently at latest, 1.29.0)
  moves to @hono/node-server 2.x.
